# Dynamic Widget

Windows 10/11 uchun ekran tepasidagi "Dynamic Island" uslubidagi widget: soat, musiqa va qo'shiq matni,
ob-havo, kalendar, tizim holati, pomodoro, ekran yozuvi, rasm/video konvertatsiya, fasl animatsiyalari.

## O'rnatish

1. [**DynamicWidget-Setup.exe ni yuklab oling**](https://github.com/nsv-gallery/DynamicWidget/releases/latest/download/DynamicWidget-Setup.exe)
2. Ishga tushiring. Windows "Windows protected your PC" desa: **More info → Run anyway**
   (dastur pullik sertifikat bilan imzolanmagan, xavfli emas).
3. Tayyor. Sichqonchani ekranning o'rta-tepasiga olib boring.

Python yoki boshqa narsa o'rnatish shart emas. Administrator huquqi so'ralmaydi.

## Yangilanish

Widget yangi versiyani o'zi tekshiradi, yuklab oladi va o'rnatadi. Sizning sozlamalaringiz saqlanib qoladi.
Qo'lda tekshirish: tray ikonkasi (soat yonida) → **Yangilanishni tekshirish**.

## O'chirish

Windows Sozlamalari → Ilovalar → **Dynamic Widget** → O'chirish.
